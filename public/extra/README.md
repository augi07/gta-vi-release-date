# Extra backgrounds

Place optional GTA VI background images and videos in this folder.

The website's **Upload image or video** setting can open any of these files directly. Supported formats depend on the browser; WebP/JPEG/PNG images and MP4/WebM videos are recommended.

Because a static browser page cannot automatically list files in a local folder, new files are selected through the upload control. If the site later gains a server or build step, this folder can be indexed automatically.
